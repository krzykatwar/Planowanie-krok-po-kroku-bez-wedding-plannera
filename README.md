# Planowanie ślubu — planer krok po kroku

Lekki, statyczny planer do wspólnego układania przygotowań. Zawiera brief, listę zadań, podsumowanie budżetu, porównanie usług, licznik odpowiedzi gości, szkic dnia oraz prosty wariant zapasowy.

## Jak korzystać

- Wpisy zapisują się automatycznie w pamięci lokalnej bieżącej przeglądarki.
- Plan nie jest wysyłany na serwer; nie ma konta, płatności ani zewnętrznego API.
- „Drukuj plan” otwiera systemowe okno drukowania. Można z niego wydrukować kartki albo zapisać je jako PDF.
- „Wyczyść zapisany plan” usuwa lokalne wpisy z tej przeglądarki.

## Podgląd lokalny

Otwórz `index.html` w przeglądarce. Projekt nie wymaga instalowania pakietów ani procesu budowania.

## Publikacja w Netlify

Zaimportuj repozytorium do Netlify i ustaw katalog publikacji na `.`. Konfiguracja znajduje się w `netlify.toml`.

## Zakres

Strona jest wyłącznie narzędziem organizacyjnym. Nie zawiera informacji prawnych, porad o formalnościach, umowach ani opłatach. Nie zawiera też sklepu ani pełnego pliku e-booka.
